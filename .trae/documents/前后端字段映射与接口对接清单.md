# 前后端字段映射与接口对接清单

## 1. 目标与范围
- 覆盖链路：商品浏览 → 商品详情与 SKU 选择 → 加入购物车 / 直接结算 → 订单预览 → 创建订单 → Mock 支付 → 订单列表。
- 仅支持登录用户（Sa-Token 登录态）。
- SKU 规格统一使用结构化 `attributes`，不再依赖前端 JSON.parse。

## 2. 接口总览

### 2.1 商品
- `GET /product/list?pageNum=1&pageSize=10`
- `GET /product/{id}`

### 2.2 购物车
- `POST /cart/add`
- `GET /cart/list`
- `PUT /cart/{id}`
- `DELETE /cart/{id}`

### 2.3 地址
- `GET /address/list`
- `POST /address`
- `PUT /address/{id}`
- `DELETE /address/{id}`
- `PUT /address/{id}/default`

### 2.4 订单 / 支付
- `POST /order/preview`
- `POST /order/create`
- `POST /order/pay`
- `GET /order/list`
- `GET /order/{id}`
- `PUT /order/{id}/cancel`

## 3. 关键字段映射

## 3.1 商品列表（首页/列表页）
- 前端使用字段：`id,title,price,compareAtPrice,pic,tags,images`
- 后端返回 VO：`ProductVO`
- 数据库来源：
  - `pms_product.id` → `id`
  - `pms_product.name`(多语言) → `title`
  - `pms_product.price` → `price`
  - `pms_product.compare_at_price` → `compareAtPrice`
  - `pms_product.pic` → `pic`
  - `pms_product.tags` → `tags`
  - `pms_product.images` → `images`

## 3.2 商品详情 + SKU 规格
- 前端详情页核心：
  - 商品：`title,price,compareAtPrice,specs,quickKnow,upsells`
  - SKU：`skuList[].id,skuList[].price,skuList[].stock,skuList[].attributes`
  - 可选项：`skuAttributeOptions.style/bundle/color`
- 后端返回 VO：
  - `ProductVO.quickKnow`：结构化对象/数组
  - `ProductVO.skuList`：`List<SkuVO>`
  - `ProductVO.skuAttributeOptions`：由 SKU attributes 聚合生成
- 数据库来源：
  - `pms_product.quick_know` → `quickKnow`
  - `pms_sku.specs(JSONB)` → `SkuVO.attributes`

## 3.3 加入购物车
- 请求：`POST /cart/add`
```json
{
  "productId": 1,
  "skuId": 2,
  "quantity": 1
}
```
- 前端来源：详情页选中的 `selectedSku.id` + `quantity`
- 数据库落库：
  - `oms_cart_item.product_id`
  - `oms_cart_item.sku_id`
  - `oms_cart_item.quantity`
  - `oms_cart_item.selected_attributes_snapshot`

## 3.4 购物车列表（侧边栏/结算页）
- 返回：`List<CartItemVO>`
```json
{
  "cartItemId": 10,
  "productId": 1,
  "skuId": 2,
  "title": "isinwheel S9 Pro...",
  "productPic": "https://...",
  "unitPrice": 529.99,
  "quantity": 1,
  "lineAmount": 529.99,
  "attributes": {"style":"2026 Upgraded Edition","bundle":"S9 Pro*2","color":"Black"},
  "stock": 80
}
```

## 3.5 地址管理
- 创建/更新请求字段：
  - `country,firstName,lastName,phone,addressLine1,addressLine2,city,state,zipCode,isDefault`
- 数据库存储：`ums_user_address.*`
- 结算页回填策略：`/address/list` 中 `isDefault=true` 优先，其次第一条。

## 3.6 订单预览
- 请求（购物车模式）：
```json
{
  "source": "cart",
  "cartItemIds": [10, 11]
}
```
- 请求（直接结算模式）：
```json
{
  "source": "direct",
  "items": [{"productId":1,"skuId":2,"quantity":1}]
}
```
- 响应：`OrderPreviewVO`
  - `items,subtotal,shippingAmount,discountAmount,totalAmount`

## 3.7 创建订单
- 请求：`POST /order/create`
  - `source: cart | direct`
  - `cartItemIds` 或 `items`
  - `addressId`（可选）或 `addressSnapshot`
  - `paymentMethod,shippingMethod,discountAmount`
- 订单表字段映射：
  - `source` → `oms_order.checkout_source`
  - `paymentMethod` → `oms_order.payment_method`
  - 地址快照 → `receiver_*` 扩展字段
  - 价格 → `total_amount,shipping_amount,discount_amount`

## 3.8 支付确认（Mock）
- 请求：`POST /order/pay`
```json
{
  "orderId": 1001,
  "paymentMethod": "credit_card",
  "mockResult": "success"
}
```
- 状态流转：
  - 成功：`pay_status=1,status=1,pay_time,pay_txn_no`
  - 失败：`pay_status=2,status=0`

## 4. 前端页面与接口对应关系
- 商品详情页：`pages/products/[id].vue`
  - 读：`/product/{id}`
  - 写：`/cart/add`
  - 直结：跳转 `/checkout?source=direct&productId&skuId&quantity`
- 购物车侧栏：`components/CartSidebar.vue`
  - 读：`/cart/list`
  - 改：`PUT /cart/{id}`
  - 删：`DELETE /cart/{id}`
- 结算页：`pages/checkout.vue`
  - 地址：`/address/list`
  - 预览：`/order/preview`
  - 创建：`/order/create`
  - 支付：`/order/pay`
- 订单页：`pages/account/orders.vue`
  - 读：`/order/list`
- 个人中心地址：`pages/account/profile.vue`
  - 读：`/address/list`
  - 新增：`POST /address`

## 5. 数据库操作脚本
- 建表与初始数据：`backend/src/main/resources/schema.sql`
- Mock 数据补充：`backend/src/main/resources/mock_data_insert.sql`
- 清理脚本：`backend/src/main/resources/mock_data_cleanup.sql`

## 6. 联调检查清单
- 详情页切换不同规格，`skuId` 会变化且加购请求携带正确。
- 购物车侧栏展示标题/图片/单价/小计，不再显示占位字段。
- checkout 在 cart/direct 两种来源下都能预览金额并下单。
- 有默认地址时自动回填，无地址时可手动输入并带快照下单。
- Mock 支付成功后订单状态可在订单页读取。
