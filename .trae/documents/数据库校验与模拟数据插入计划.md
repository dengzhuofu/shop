# 数据库结构校验与模拟数据插入计划

## 1. 目标与现状分析
- **目标**: 连接本地 PostgreSQL 数据库，校验实际数据库表字段与后端 Java 实体类是否匹配，并向数据库中插入符合电商网站风格的模拟数据（使用在线真实图片链接）。
- **当前状态**: 
  - 数据库配置（基于 `application.yml`）：`jdbc:postgresql://localhost:5432/shop`，用户名 `postgres`，密码 `1st1st1st`。
  - 后端实体类（`com.shop.entity.*`）已定义好，包括 `PmsProduct`、`PmsSku`、`PmsReview` 等。
  - 需要在真实数据库中验证这些结构，并填充丰富的数据以便前端页面（如商品列表、详情页）展示。

## 2. 执行步骤

### Step 1: 数据库连接与字段校验
- **操作**: 编写一个临时诊断脚本（Node.js 或 Python），使用 `application.yml` 中的凭证连接到本地 PostgreSQL 数据库。
- **校验内容**: 查询 `information_schema.columns` 获取 `pms_product`、`pms_sku`、`oms_order` 等核心表的实际字段。
- **比对逻辑**: 将读取到的数据库实际字段与后端 `src/main/java/com/shop/entity/` 目录下的 Java 实体类字段进行一一比对，确认是否存在遗漏或类型不匹配的情况。
- **输出**: 在控制台输出校验报告。

### Step 2: 生成电商模拟数据 (Mock Data)
- **操作**: 编写一个新的 SQL 数据插入脚本 `backend/src/main/resources/ecommerce_mock_data.sql`。
- **数据内容**:
  - 新增 4-6 款具有代表性的电商产品（如：新款越野电动滑板车、城市通勤折叠自行车、智能头盔配件等）。
  - **图片资源**: 使用高质量的 Unsplash 真实图片链接（如 `https://images.unsplash.com/photo-...`）作为商品主图 (`pic`) 和轮播图 (`images`)。
  - **规格数据**: 为每个产品插入对应的 SKU 规格（如不同颜色、电池容量的版本）及相应的价格和库存。
  - **评论数据**: 插入一些带有真实语气的用户评价，丰富详情页的展示效果。

### Step 3: 自动更新并写入数据库
- **操作**: 使用命令行工具（如 `psql`）或通过 Node.js/Python 脚本直接执行上述生成的 `ecommerce_mock_data.sql` 文件。
- **验证**: 执行完成后，通过脚本或接口查询刚才插入的商品数据，确保数据已经成功落库。

## 3. 假设与前置条件
- 本地 PostgreSQL 服务 (5432端口) 正在运行，且数据库 `shop` 存在。
- 允许在项目目录中临时安装数据库连接驱动（如 `pg` npm 包）以完成校验和插入任务，任务完成后可清理。
